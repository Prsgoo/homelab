# Games Services (CT 304)

→ [CT 304 spec](../../lxcs/media-games.md)

Game library and ROM management stack running on CT 304.

## RomM

→ [RomM](romm.md)

Self-hosted game library. Manages ROM files and virtual catalog entries (file-less) for platforms like Steam and Xbox. IGDB, ScreenScraper, SteamGridDB and Hasheous for metadata.
